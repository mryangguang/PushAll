PushAll 消息中心 v0.1.12（Windows 便携版）
==========================================

【启动】
1. 解压整个文件夹（不要只拷贝 exe）。
2. 双击 PushAll.exe。
3. 关闭或最小化窗口会收进系统托盘；右键托盘图标可：
   - 打开主界面
   - 重启服务
   - 退出

【自动更新】
程序启动后会自动向 GitHub Releases 检查新版本，发现新版本会把该版本的更新说明和版本号一起弹窗展示。
更新只替换程序文件，data、plugins、logs 会保留。

设置页「更新代理」可配置 HTTP / HTTPS / SOCKS5，仅用于检查与下载新版本。

如果下载慢或超时：
1. 用浏览器下载 PushAll-<版本>-win64.zip
2. 放到 data\updates\ 目录（文件名保持 Release 上的名字）
3. 打开设置页点「下载并更新」，会优先使用本地包

【数据位置】（都在 exe 同目录）
  data\pushall.db   配置与运行记录
  plugins\          第三方插件
  logs\desktop.log  桌面端日志

【首次运行提示】
- Windows 可能提示“未知发布者”，选择“更多信息 → 仍要运行”。
- 程序只监听 127.0.0.1:8765，仅本机访问。
- 如果桌面窗口打不开（缺少 WebView2），会自动改用默认浏览器，托盘仍然可用。

【卸载】
退出托盘程序后，直接删除整个文件夹即可，不写注册表。
