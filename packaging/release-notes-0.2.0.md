## AI 处理（新增）

- 设置页新增「AI 模型」：支持多个模型，可设默认模型与全局备用模型（内网网关，OpenAI 兼容接口）
- 数据源新增「AI 处理」：取数后按自然语言要求过滤、打标（仅 `AI_` 前缀字段）、排序、取前 N、写汇总，再交给模板
- 模型不能新增行、不能改原字段；输出严格 JSON 校验，非法返回按失败处理
- 主模型失败自动重试一次，再切换全局备用模型；仍失败按策略执行：「推送 AI 报错提示」（可用独立报错模板）或「照常推送全部」
- 数据源新增「测试AI（不推送）」：取前 20 行试跑，展示保留/过滤明细与每条原因
- 运行记录新增 AI 步骤：模型、耗时、保留/过滤条数、每条过滤原因、汇总、是否使用备用模型
- 模板新增变量：`ai.summary` / `ai.kept` / `ai.dropped` / `ai.model` / `ai.fallback_used`

## 说明

- 更新只替换程序文件，`data`、`plugins`、`logs` 均保留
